# Mon RPG Godot 4

## Lancer le jeu

1. Ouvrir Godot 4
2. Ouvrir le projet depuis ce dossier
3. Cliquer sur Play

## Contrôles

- ZQSD / flèches : bouger
- Espace : attaquer
- H : potion
- E : interagir avec le marchand

## Ce que contient la version actuelle

- personnage principal
- ennemis au contact
- zone de jeu
- vie, or, potions
- boutique simple
- inventaire simple
- HUD dynamique
